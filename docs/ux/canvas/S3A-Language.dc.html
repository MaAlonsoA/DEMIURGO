Visual language

Dots say how sure. Bars say how far. Color says what it asks of you. Icons say what it is.

Dots · how sure

ConfirmedA person said yes.
AssumedDEMIURGO concluded it.
ProposedSuggested, waiting for you.
OpenAsked, no answer yet.
?UnknownNot asked yet.
Not active
ParkedKept for later.
DroppedDoesn't apply.
ReplacedA newer version exists.

Bars · how far · features

Three bars: ready · built · verified
Not readySomething still blocks it.
Ready to buildConfirmed, nothing blocks it.
BuildingAn agent is on it.
VerifiedEvery check passed.
Re-checkChanged after it was verified.

Only features have bars. Everything else has only a dot.

Color · what it asks of you

Ink · settledNothing to do.
Blue · needs youThe only color that asks for you.
Amber · workingDEMIURGO or an agent is on it.
Rust · problemA conflict, a block, a re-check.
Grey · not activeParked, dropped or replaced.

Confirmed and Assumed have no color of their own. To check assumptions, turn on the Assumed lens.
