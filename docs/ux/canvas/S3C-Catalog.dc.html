Rules of the language

  • One state per card: one shape, one word.
  • Blue only ever means "needs you".
  • Signals show only when not zero, four at most.
  • Dots say how sure; bars (features only) say how far.
  • Every symbol explains itself on hover.
  • Codes like FDR-INS-001 live only in the detail.
  • A signal takes the color of its most urgent part.
  • Confirmed and Assumed have no color; use the Assumed lens.
