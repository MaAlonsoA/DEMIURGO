A stroke icon on the 24 grid, round caps and joins, in currentColor: the type icons (1.8 stroke) and the signal icons (2 stroke) the other components draw.

Names: the types (`feature`, `decision`, `tech-decision`, `question`, `check`, `idea`, `thread`, `journey`, `bug`) and `depends-on`, `conflict`, `needs-review`, `blocked`, `clock`, `plug`, `automatic`, `info`, `close`. No emoji and no icon library.

```jsx
<Icon name="conflict" size={14} stroke={2} />
```
